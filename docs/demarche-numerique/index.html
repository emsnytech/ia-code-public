Méthode

Source : l'historique Git public du dépôt demarche-numerique/demarche.numerique.gouv.fr, branche main, du 14 octobre 2021 au 14 octobre 2026. Une ligne = une pull request fusionnée (ou un commit poussé directement sur main). « En production » = la première version datée (étiquettes AAAA-MM-JJ-NN utilisées pour les déploiements) qui contient la fusion.

Tous les classements sont automatiques, par mots-clés sur le titre et la branche, complétés par les fichiers modifiés. Ils sont fiables en tendance, pas ligne à ligne. « Avec Claude » = au moins un commit porte « Co-Authored-By: Claude » ; c'est un minimum.

Nature (une seule par ligne, dans cet ordre de priorité)

Sécurité
Authentification, 2FA, sessions, CSP, assainissement, limitation de débit, droits d'accès, antivirus, chiffrement.
Accessibilité
a11y, RGAA, ARIA, lecteur d'écran, navigation clavier, contrastes.
Dépendances
Montées de version de gems, paquets JS, Ruby, Rails, DSFR ; PR Dependabot.
Tests & qualité
Specs, tests systèmes, tests instables, Rubocop, intégration continue.
Performance
N+1, optimisation, cache, index, temps de réponse, mémoire.
API & interopérabilité
API GraphQL, webhooks, API Entreprise / Particulier, FranceConnect, ProConnect, SIRET, référentiels, Chorus, API Géo.
Design & ergonomie
DSFR, mise en page, affichage, mobile, menus, boutons, mode sombre, refontes.
Contenus & libellés
Wording, traductions, FAQ, documentation, coquilles.
Fonctionnalité
Évolution métier qui ne relève d'aucune nature ci-dessus.
Correctif
Correction de bug qui ne relève d'aucune nature ci-dessus.
Technique & maintenance
Refactorisation, migrations, nettoyage, feature flags, tâches.

Public concerné

Lu dans la formule « ETQ (en tant que) usager / instructeur / admin… » quand elle existe, sinon dans le titre, sinon d'après les dossiers de code modifiés (contrôleurs et vues usagers, instructeurs, administrateurs, manager, API). « Équipe technique » = invisible pour les utilisateurs ; « Transverse » = touche l'interface sans public identifiable.

Type

Évolution, correctif, technique ou non classé : c'est le premier classement, celui de la vue d'ensemble. Une évolution peut avoir pour nature Design, API, Accessibilité, etc.

Données : historiques Git publics sur GitHub, lus le 14 octobre 2026. Méthode, scripts et fichiers CSV : dépôt du projet. Charte FORM 2026.
