Méthode

Périmètre. 33 dépôts GitHub publics de services numériques de l'État et d'opérateurs publics, choisis parmi les plus actifs (liste et liens dans le tableau ci-dessous). Période : du 14 octobre 2024 au 14 octobre 2026. Les sources sont l'historique Git public de chaque dépôt, lu le 14 octobre 2026.

Changement. Une unité intégrée à la branche principale de développement : une pull request fusionnée, ou un commit « squashé » ou « rebasé ». Les changements faits uniquement par des robots (Dependabot, Renovate, GitHub Actions…) sont écartés. Pour Tchap, les synchronisations avec le code amont d'Element sont écartées.

Mise en production. Selon le fonctionnement de chaque dépôt : première version publiée (étiquette) qui contient le changement ; arrivée sur la branche de production quand il y en a une ; à défaut, date de fusion (déploiement continu).

Évolution. Classement automatique sur le titre (feat, ✨, « ajout », « ETQ »…). Indicatif.

Trace de Claude. Au moins un commit du changement porte « Co-Authored-By: Claude », « Generated with Claude Code », un lien claude.ai/code, ou a pour auteur l'application Claude. Les autres assistants sont repérés de la même façon : Copilot, Cursor, Codex, Gemini, Mistral, etc.

Ce que la mesure ne voit pas. Ces mentions sont ajoutées par défaut par Claude Code, mais chaque développeur peut les désactiver, et elles disparaissent quand on réécrit le message de commit. Un usage de Claude en conversation, en relecture ou par copier-coller ne laisse aucune trace. Les chiffres sont donc un minimum. Les fichiers d'instructions pour agents (CLAUDE.md, AGENTS.md…) sont un second indice, indépendant, d'un usage par l'équipe.
